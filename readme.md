\# Simple Background Color Remover



A clean, browser-based image tool built with HTML, CSS, and JavaScript that erases solid background colors and lets you download transparent PNGs instantly.

[click to view](https://minshida-latheef.github.io/background-color-remover/)

\## What It Does

\- \*\*Upload Any Image:\*\* Load local images directly onto an HTML5 `<canvas>` without uploading to a server.

\- \*\*Target Color Selection:\*\* Pick any background color (defaults to `#ffffff`) to erase.

\- \*\*Tolerance Slider:\*\* Adjust color sensitivity from `0` to `150` for cleaner edges.

\- \*\*Transparency Grid:\*\* Preview erased pixels over a checkerboard pattern before saving.

\- \*\*One-Click Export:\*\* Download the final transparent image as a `.png` file.



\## Repository Files

\- `index.html` — Layout, color picker, tolerance slider, and canvas

\- `style.css` — Card styling and checkerboard transparency background

\- `script.js` — Image loading, RGB distance calculation, and PNG download



\## Run Locally

Download or clone the repository and open `index.html` in any modern web browser.
